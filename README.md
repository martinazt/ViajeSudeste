# 🌴 SE Asia Girls Trip ✨ | Dashboard & Itinerario de Viaje

Dashboard interactivo y planificador completo para el viaje al Sudeste Asiático (Singapur ➔ Bali ➔ Vietnam ➔ Tailandia).

## 🚀 Contenido del Proyecto

- **`dashboard_viaje.html`**: Dashboard principal interactivo con:
  - Mapa dinámico con Leaflet (rutas, pines y paradas).
  - Itinerario día a día detallado.
  - Control de presupuesto y gastos estimados.
  - Recomendaciones de alojamientos (hostels, guesthouses y villas).
  - Logística, requisitos de salud y visados.
- **`SudesteTrip/`**: Versión complementaria y recursos del viaje.

## 📱 ¿Cómo visualizarlo?

### Opción 1: Local
Simplemente abre el archivo [dashboard_viaje.html](dashboard_viaje.html) con doble clic en cualquier navegador web (Chrome, Edge, Safari, Firefox).

### Opción 2: GitHub Pages (Recomendado para verlo en el celular)
Para acceder al dashboard desde cualquier dispositivo sin instalar nada:
1. Ve a los ajustes del repositorio en GitHub (**Settings** > **Pages**).
2. En **Build and deployment** > **Branch**, selecciona `main` y guarda.
3. ¡Listo! Tendrás un enlace web público o privado para ver y consultar tu viaje en tiempo real desde el celular.
